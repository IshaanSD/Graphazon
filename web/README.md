# Graphazon Web

Frontend for the Graphazon project. Currently a minimal landing page (project
description + link to the [GitHub repo](https://github.com/IshaanSD/Graphazon)),
built to later grow into a demo/dashboard for query understanding, knowledge
graph visualization, and ranking results.

Stack: React + TypeScript + Vite + Tailwind CSS.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
